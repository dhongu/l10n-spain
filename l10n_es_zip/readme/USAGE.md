1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the Spanish localities of that postal code are listed with their province.

   ![Cities list filtered on the postal code 01007: the localities Armentia, Vitoria-Gasteiz, all of the state Araba/Álava (ES)](static/description/en/01_lista_localitati_cap.png)

2. Open a Spanish contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in Spain: the postal code 01160 fills in the city Ibarra and the state Araba/Álava (ES)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in Spain: the postal code 01007 fills in the state Araba/Álava (ES); the city field lists the localities of 01007](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Spain: set city from ZIP*.

   ![Contacts list with Spanish contacts selected and the Actions menu open on Spain: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Customer Armentia after the action: ZIP 01007, city Armentia (01007) and state Araba/Álava (ES)](static/description/en/05_contact_dupa_actiune.png)
