1. Open *Contacts → Configuration → Localities* (developer mode) and filter on a postal code: the
   Spanish localities of that postal code are listed with their region.
2. Open a Spanish contact and type the postal code in the address: the city and the region are filled in.
3. When the postal code is shared by several localities, only the region is filled in; choose the city from
   the list (type the postal code or the name in the city field).
4. To fix the existing contacts, select them in the contacts list and use
   *Actions → Spain: set city from ZIP*.
